# pink-spider.github.io

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-live-222222?logo=githubpages&logoColor=white)](https://pink-spider.github.io/)
[![Hugo](https://img.shields.io/badge/Hugo-FF4088?logo=hugo&logoColor=white)](https://gohugo.io/)

Pink Spider 기술 블로그 <https://pink-spider.github.io> 의 **Hugo 빌드 결과물**입니다.
소스는 비공개 저장소 `Pink-Spider/blog`에 있습니다.

**이 저장소는 직접 수정하지 않습니다.** 배포 스크립트(`deploy.sh`)가 `--cleanDestinationDir`로
전체를 다시 생성해 덮어쓰므로, 여기서 고친 내용은 다음 배포 때 사라집니다.
글·테마·설정은 `blog` 저장소에서 고치고 `./deploy.sh`로 발행합니다.

이 README 자체도 `blog/static/README.md`에서 복사됩니다.
